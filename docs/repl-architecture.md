# Erg REPL Architecture Report

## 概要

このドキュメントはErg REPLのアーキテクチャを詳細に説明します。

---

## 1. エントリーポイント

### メインエントリー: `src/main.rs`

- `ErgMode::Execute` の場合、`DummyVM::run()` にルーティング
- `exec_new_thread(run, "erg")` でスレッド内で実行をラップ

### REPL検出: `crates/erg_common/io.rs`

- `InputKind::is_repl()` でREPLモードを検出
- `InputKind::REPL` または `InputKind::DummyREPL(_)` の場合にREPLがトリガー

---

## 2. コアコンポーネント

### VirtualMachine (状態追跡) - `crates/erg_common/traits.rs`

**構造:**

```rust
pub struct VirtualMachine {
    pub codes: String,              // 現在のブロックの累積ソースコード
    pub now_block: Vec<BlockKind>,  // ネストされたブロック種類のスタック
    now: BlockKind,                 // 現在の最内ブロック (private)
    pub length: usize,              // インデントレベル/ネスト深度
}
```

**役割:**

- 複数行入力状態の管理
- ブロックネスティングの追跡
- 適切なPythonコード生成のためのインデントレベル維持

**メソッド:**

| メソッド | 説明 |
|----------|------|
| `now()` | 現在のブロック種類を取得 (getter) |
| `push_block_kind()` | 新しいブロックコンテキストに入る |
| `remove_block_kind()` | ブロックを抜ける (Mainブロックは削除しない) |
| `reset_to_main()` | エラー回復用にMain状態にリセット |
| `push_code()` | ソース行を蓄積 |
| `clear()` | 次の入力のためにリセット |
| `indent()` | インデント文字列を生成 |

### BlockKind Enum

異なる構文コンテキストを表現:

```rust
pub enum BlockKind {
    Main,           // ルートレベル - 常に存在
    Assignment,     // '=' で終わる行
    ClassPriv,      // プライベートクラスアクセス '::'
    ClassPub,       // パブリッククラスアクセス '.'
    ColonCall,      // メソッド呼び出し ':'
    Error,          // パーサーエラー (即時評価をトリガー)
    Lambda,         // 関数/ラムダ ('=>', '->', 'do', 'do!')
    AtMark,         // デコレータ '@'
    MultiLineStr,   // 三重クォート文字列 '"""'
    ClassDef,       // クラス定義
    Collections,    // ブラケット/ブレース/パーレン '{', '(', '['
    None,           // 単一行ステートメント (即時評価)
}
```

### StdinReader (入力処理) - `crates/erg_common/stdin.rs`

**デュアルモードサポート:**

| モード | 機能 |
|--------|------|
| **Full REPL** (`feature = "full-repl"`) | 履歴、タブ補完、クリップボード対応 |
| **Basic REPL** | シンプルなBufReaderベースのstdin |

**フィールド:**

```rust
pub struct StdinReader {
    block_begin: usize,      // 現在のブロックが開始した行番号
    lineno: usize,           // 現在の行番号
    buf: Vec<String>,        // 履歴バッファ
    indent: u16,             // 現在のインデントレベル
    history_input_position: usize, // 履歴ナビゲーション用 (full-repl only)
}
```

**Full-REPL機能 (crosstermベース):**

- タブ補完 (シンボルマッチング)
- 履歴ナビゲーション (上下矢印)
- カーソル移動 (Home/End/Left/Right)
- クリップボード対応 (Ctrl+V)
- Ctrl+D/Ctrl+Z で終了
- 動的行リフレッシュ

### Runnable Trait - `crates/erg_common/traits.rs`

REPLのRead-Eval-Print-Loopを実装する中心的なインターフェース:

**必須メソッド:**

| メソッド | 説明 |
|----------|------|
| `cfg()` / `cfg_mut()` | 設定へのアクセス |
| `initialize()` | エラー回復用の状態リセット |
| `clear()` | 入力間の可変状態消去 |
| `exec()` | ファイルベース入力の実行 |
| `eval(src: String)` | 単一入力の評価 |
| `expect_block(src: &str)` | 継続必要性の予測 |
| `finish()` | 終了時のクリーンアップ |

**オプションメソッド:**

| メソッド | 説明 |
|----------|------|
| `get_completions()` | タブ補完用シンボルリスト提供 |
| `start_message()`, `ps1()`, `ps2()` | REPLプロンプトとメッセージ |
| `quit()`, `quit_successfully()` | 終了ハンドラー |

## 4. 状態管理

### VirtualMachine 状態ライフサイクル

```
┌──────────────────────────────────────────────────────┐
│ ループ開始時に Main ブロックで作成:                   │
│ VirtualMachine::new() → now_block=[Main], now=Main   │
├──────────────────────────────────────────────────────┤
│ 入力ごと:                                            │
│  1. 行読み取り → expect_block() 呼び出し            │
│  2. ブロックスタック変更 (push/pop/reset)            │
│  3. codes バッファに蓄積                             │
│  4. 完了チェック (空入力または明示的終了)            │
│  5. 完了時: eval(codes) → clear()                   │
├──────────────────────────────────────────────────────┤
│ vm.clear():                                          │
│  - codes.clear()                                     │
│  - now_block = vec![Main]                            │
│  - now = Main                                        │
│  - length = 1                                        │
│                                                      │
│ (StdinReader やシンボルコンテキストはリセットしない) │
└──────────────────────────────────────────────────────┘
```

### 補完キャッシュ

評価成功後に更新されるスレッドセーフなグローバルキャッシュ:

```rust
static COMPLETION_CACHE: OnceLock<Shared<Vec<String>>> = OnceLock::new();

// eval 後に更新
instance.get_completions()  // Compiler.dir() をクエリ
  → crate::stdin::set_completion_cache(symbols)
```

## 5. アーキテクチャ層

### DummyVM (ハイブリッドインタープリター) - `src/dummy.rs`

Ergコンパイラと Python インタープリター間の仲介:

**コンポーネント:**

```rust
pub struct DummyVM {
    compiler: Compiler,          // 型チェック + コード生成
    stream: Option<MessageStream<TcpStream>>,  // Python サーバーへの TCP
}
```

**メッセージプロトコル (3バイトヘッダー + データ):**

```
┌────────┬───────────┬──────────────┐
│ Inst   │ Size (BE) │ Data         │
│ 1 byte │ 2 bytes   │ n bytes      │
└────────┴───────────┴──────────────┘
```

**命令セット:**

| Inst | 値 | 方向 | 意味 |
|------|-----|------|------|
| UNKNOWN | 0x00 | - | 無効 |
| PRINT | 0x01 | S→C | 出力/結果 |
| LOAD | 0x02 | C→S | モジュールインポート |
| EXCEPTION | 0x03 | S→C | ランタイムエラー |
| INITIALIZE | 0x04 | S→C | エラー時リセット |
| EXIT | 0x05 | 双方向 | シャットダウン |
| EXECUTE | 0x06 | C→S | Python コード実行 |

### Python REPL サーバー - `src/scripts/repl_server.py`

- 空きTCPポートでサブプロセスとして起動
- Python 実行コンテキスト維持 (`ctx = {"importlib": importlib}`)
- バイトコードを受信、`exec()` で実行
- stdout + 例外を返却

## 7. 現在の制限と改善点

### 既知の制限

1. **限定的なイントロスペクション**
   - 型情報はデフォルトで表示されない (`--show-type` のみ)
   - リアルタイムで値や型を検査できない

2. **セッション永続性なし**
   - Python REPL サーバーは実行ごとに起動
   - シンボルキャッシュは現在セッション限定
   - 履歴のディスク永続化なし

3. **ブロック検出ヒューリスティクス**
   - `expect_block()` はパーサー試行コンパイルを使用 (高コスト)
   - パターンマッチングがやや単純

4. **パフォーマンス**
   - 毎回の eval で TCP 通信オーバーヘッド
   - コンパイル済みコードオブジェクトのキャッシュなし
   - 各 eval で完全再コンパイル

5. **エラー回復**
   - `reset_to_main()` でネストブロックパースが失敗するとコンテキストを失う
   - 特定の構文エラーで不完全なエラーメッセージ

6. **テスト**
   - REPL テストは全て `#[ignore]` (CI で実行されない)

### 改善の機会

1. **永続 REPL サーバー**
   - 複数の呼び出し間で Python サブプロセスを維持
   - 長寿命セッション用の IPC メカニズム実装

2. **より良いブロック検出**
   - パース結果をキャッシュ、試行コンパイル削減のヒューリスティクス改善
   - インクリメンタルパーサーで高速ブロック検出

3. **シンボルイントロスペクション**
   - `get_var_info()` を公開して REPL で型表示
   - `:info` コマンドでシンボル検査
   - 代入後に推論された型を表示

4. **コードキャッシュ**
   - 変更されていない定義のコンパイル済みバイトコードをキャッシュ
   - シンボル再利用時に再コンパイルをスキップ

5. **履歴とセッション管理**
   - REPL 履歴をファイルに永続化
   - `:history` コマンド追加
   - セッション状態の `:load` と `:save` サポート

## 8. テストインフラ

### DummyREPL (テスト用) - `tests/common.rs`

ユーザー入力をシミュレートするテストヘルパー:

```rust
pub fn _exec_repl(name: &'static str, lines: Vec<String>) -> Result<ExitStatus, CompileErrors> {
    let cfg = ErgConfig {
        input: Input::dummy_repl(DummyStdin::new(name.to_string(), lines)),
        quiet_repl: true,
        ..Default::default()
    };
    let stat = <DummyVM as Runnable>::run(set_cfg(cfg));
    Ok(stat)
}
```

**DummyStdin** - `crates/erg_common/io.rs`:

- 事前入力された行バッファ
- `read_line()` で順次読み取り
- 行が尽きると `exit()` で終了
- 決定論的テストのため実際の stdin の代わりに使用
